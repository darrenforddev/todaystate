# TodayState Design System

Version: 1.0

---

# Philosophy

TodayState should feel like a premium financial intelligence platform.

The interface should always feel:

• Calm
• Professional
• Elegant
• Explainable
• Fast

Never noisy.

Never cluttered.

Never overwhelming.

---

# Design Principles

1. Clarity before decoration.

2. Evidence before opinion.

3. Every screen should answer one question well.

4. White space improves thinking.

5. Intelligence should feel effortless.

# MBIE Style

Every MBIE opinion should be

Objective

Evidence-based

Clear

Professional

Never sensational.

Never emotional.

Never use unnecessary hype.

Always explain.

---

# User Experience Goals

The user should understand

Where they are.

Why it matters.

What changed.

What they should watch next.

Within ten seconds.

---

# Long-Term Goal

When someone opens TodayState they should immediately feel informed, calm and confident.

The interface should reduce uncertainty, not create it.
